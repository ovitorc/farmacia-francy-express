# Francy Connect Pharmacy

Crie um site completo, profissional, moderno, responsivo e funcional para a **Farmácias Francy**, uma farmácia física já existente.

O objetivo é criar uma experiência semelhante à de uma grande farmácia virtual, porém com aparência clean, confortável, confiável e intuitiva. O cliente deve conseguir encontrar produtos rapidamente, navegar pelas categorias, visualizar detalhes, adicionar produtos ao carrinho e, no final, enviar o pedido diretamente pelo WhatsApp da Farmácias Francy.

IMPORTANTE: todas as imagens dos produtos, a logo da Farmácias Francy, a imagem do Farmácia Popular, a logo da ANVISA e demais imagens necessárias serão fornecidas por mim dentro do projeto. Utilize os arquivos enviados como referência principal e não substitua as imagens fornecidas por imagens genéricas.

A identidade visual deve transmitir:

* Farmácia profissional
* Confiança
* Limpeza
* Saúde
* Organização
* Modernidade
* Facilidade de compra
* Conforto para o cliente

Use principalmente:

* Vermelho da identidade: #ef1925
* Branco vivo: #FFFFFF

O azul #1b2268 deve ser a cor predominante da identidade, principalmente no menu superior.

O vermelho #ef1925 deve aparecer como cor de destaque, mas sem dominar a página. Utilize-o principalmente para:

* ofertas;
* etiquetas de promoção;
* preços promocionais;
* pequenos detalhes;
* indicadores;
* chamadas importantes.

O branco deve ser bastante utilizado para manter o site leve e clean.

Evite excesso de gradientes, sombras exageradas, elementos 3D ou efeitos que façam o site parecer artificial.
